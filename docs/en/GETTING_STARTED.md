# Getting Started

This guide is the shortest path from a fresh checkout to a working local build.

## 1. Requirements

- Windows 10 or newer
- Visual Studio 2022
- MSVC v143
- Windows SDK
- optional `.NET` runtime for the managed scripting sample

## 2. Open The Solution

Open [Pragma.sln](../../Pragma.sln) and select `Debug|x64`.

## 3. Build

Build the solution from Visual Studio or follow [Building](./BUILDING.md).

## 4. Run

Launch [Pragma.exe](../../x64/Debug/Pragma.exe) after a successful debug build.

## 5. First Things To Explore

- open the menu bar
- inspect `Hierarchy`
- inspect `Scene View`
- inspect `Inspector`
- try `Material Browser`
- try `Prefab Browser`
- open diagnostics windows
