# Roadmap

This roadmap reflects the current direction rather than a fixed public promise.

## Current Priorities

1. continue improving managed C# gameplay API
2. polish editor workflows
3. improve diagnostics and authoring quality
4. keep rendering stable while systems mature around it

## Near-Term

- richer managed gameplay bindings
- managed script diagnostics and reload workflow
- more editor polish
- stronger prefab and asset workflows

## Mid-Term

- broader gameplay-facing managed API
- more mature material and asset authoring
- stronger editor usability
- additional runtime systems

## Long-Term

- a more complete Unity-like workflow for PC-only game development
- a stronger managed scripting experience
- continued backend and tooling growth without breaking the engine foundation
