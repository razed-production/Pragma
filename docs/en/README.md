## Current Engine Snapshot

Pragma is a Windows desktop 3D engine for `x64` with:
- a backend-neutral `RHI` and a DX11 implementation
- a document-driven editor workflow
- scene, prefab, and material asset pipelines
- Jolt Physics integration
- native scripting and an early managed C# scripting path
