# Getting Started

Этот документ даёт самый короткий путь от свежего checkout до рабочего локального билда.

## 1. Требования

- Windows 10 или новее
- Visual Studio 2022
- MSVC v143
- Windows SDK
- optional `.NET` runtime для managed scripting sample

## 2. Открыть Solution

Откройте [Pragma.sln](../../Pragma.sln) и выберите `Debug|x64`.

## 3. Собрать

Соберите solution из Visual Studio или воспользуйтесь [Building](./BUILDING.md).

## 4. Запустить

После успешной debug-сборки запустите [Pragma.exe](../../x64/Debug/Pragma.exe).

## 5. Что Посмотреть Сначала

- верхнее меню
- `Hierarchy`
- `Scene View`
- `Inspector`
- `Material Browser`
- `Prefab Browser`
- diagnostic windows
