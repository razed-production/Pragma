## Текущий Срез Движка

Pragma это 3D-движок для Windows desktop и `x64`, в котором уже есть:
- backend-neutral `RHI` и реализация на DX11
- editor workflow на базе документов сцены
- scene, prefab и material asset pipeline
- интеграция Jolt Physics
- native scripting и ранний managed C# scripting path
