# Roadmap

Этот roadmap отражает текущее направление развития, а не жёсткое публичное обещание.

## Текущие Приоритеты

1. дальше развивать managed C# gameplay API
2. полировать editor workflow
3. усиливать diagnostics и качество authoring
4. держать rendering стабильным, пока вокруг взрослеют остальные системы

## Ближайший Этап

- более богатые managed gameplay bindings
- diagnostics и reload workflow для managed scripts
- дополнительный editor polish
- более сильный prefab и asset workflow

## Средний Горизонт

- более широкий gameplay-facing managed API
- более зрелый material и asset authoring
- более удобный editor
- новые runtime systems

## Дальний Горизонт

- более полный Unity-like workflow для PC-only разработки игр
- более сильный managed scripting experience
- дальнейший рост backend и tooling без ломки фундамента движка
